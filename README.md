# Text Expander

Небольшое приложение для Windows 11, которое живёт в трее и делает две вещи в любой программе:

1. **Подставляет шаблоны по кодовым словам.** Набираешь `%%34code` — слово стирается, на его месте появляется заранее заготовленный текст (например, шаблон кода).
2. **Исправляет текст, набранный не в той раскладке.** Набрал `ghbdtn` вместо «привет» — нажимаешь горячую клавишу, и слово исправлено.

## Горячие клавиши

| Клавиша | Что делает |
|---|---|
| **Pause** (Pause/Break) | Исправить раскладку: выделенный текст или последнее набранное слово |
| **Ctrl+Alt+Space** | То же самое — для клавиатур без Pause (ноутбуки) |

Кодовые слова срабатывают сами, без нажатия дополнительных клавиш.

## Установка и запуск

1. Установите [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64), если его ещё нет.
2. Соберите приложение (см. «Сборка») или возьмите готовый `TextExpander.exe`.
3. Запустите `TextExpander.exe` — в трее появится значок. Повторный запуск ничего не открывает: работает один экземпляр.

## Меню в трее

- **Включено** — галочка; снимите, чтобы временно отключить и шаблоны, и исправление раскладки.
- **Шаблоны…** — окно со списком кодовых слов: добавить, удалить, изменить текст, сохранить. Изменения применяются сразу.
- **Открыть файл шаблонов** — открывает `snippets.json` в редакторе.
- **Автозапуск с Windows** — запуск приложения при входе в систему.
- **Горячие клавиши…** — краткая справка по клавишам.
- **Выход**.

Подсказка с горячими клавишами видна и при наведении мыши на значок в трее, и внизу окна «Шаблоны».

## Как работают шаблоны

Шаблоны хранятся в файле `%APPDATA%\TextExpander\snippets.json`. При первом запуске он создаётся с двумя примерами:

```json
{
  "snippets": [
    { "trigger": "%%34code", "text": "public class MyClass\n{\n}" },
    { "trigger": "%%hello", "text": "Здравствуйте! Спасибо за письмо, отвечу в ближайшее время." }
  ]
}
```

- `trigger` — кодовое слово, `text` — что вставить. Текст может быть многострочным, кириллица допустима.
- Кодовое слово может быть любым, без пробелов. Префикс `%%` — просто удобное соглашение: такое сочетание не встречается в обычном тексте.
- Если файл поправить вручную, изменения подхватятся без перезапуска. Если в файле ошибка, всплывёт уведомление с номером строки, а прежние шаблоны продолжат работать.

**Что происходит при срабатывании.** Приложение следит за набираемыми символами. Как только последние набранные символы совпадают с кодовым словом:

1. Текущее содержимое буфера обмена сохраняется.
2. В буфер кладётся текст шаблона.
3. Кодовое слово стирается клавишей Backspace, затем нажимается Ctrl+V.
4. Примерно через 300 мс в буфер возвращается то, что там было раньше.

**Правила распознавания:**

- Регистр учитывается: `%%Hello` и `%%hello` — разные слова.
- Если подходят два слова (`code` и `%%code`), срабатывает более длинное.
- Если одно слово — начало другого (`%%a` и `%%ab`), короткое сработает раньше, и длинное никогда не наберётся. Окно «Шаблоны» предупреждает о таких парах.
- Набор сбрасывается при клике мышью, переключении окна, стрелках, Home/End/PgUp/PgDn, Enter, Tab, Esc и сочетаниях с Ctrl/Alt/Win. Backspace убирает последний набранный символ.
- Символы определяются по раскладке активного окна, поэтому кодовые слова могут быть и на кириллице.

## Как работает исправление раскладки

По нажатию **Pause** или **Ctrl+Alt+Space**:

1. Если в окне есть выделение, исправляется весь выделенный текст.
2. Если выделения нет, исправляется последнее набранное слово, то есть всё набранное после последнего пробела или сброса.
3. Текст переводится по клавишам: QWERTY ↔ ЙЦУКЕН, включая знаки на тех же клавишах (`;` ↔ `ж`, `'` ↔ `э`, `,` ↔ `б`, `.` ↔ `ю`, `[` ↔ `х`, `]` ↔ `ъ`, `` ` `` ↔ `ё` и т.д.).
4. Направление выбирается по буквам: если в тексте кириллица, он переводится в латиницу, иначе в кириллицу.
5. После исправления раскладка окна переключается на язык результата.

Примеры: `ghbdtn` → `привет`, `Ghbdtn` → `Привет`, `руддщ` → `hello`, `,f,f` → `баба`, `ntcn.` → `тест.`

Буфер обмена после исправления, как и после шаблонов, возвращается к прежнему содержимому.

## Ограничения

- **Окна администратора.** Windows не даёт обычной программе вводить текст в окна, запущенные от имени администратора. Для них запускайте Text Expander тоже от администратора.
- **Буфер не освобождается.** Если другая программа держит буфер обмена, вставка не выполняется, а кодовое слово остаётся на месте.
- **Точка или запятая в конце слова.** Такие символы после латинской буквы считаются знаком препинания: `ntcn.` → `тест.`. Поэтому слово, которое оканчивается на «ю» или «б» (`pyf.`), исправится как `зна.`. В таком случае исправьте его выделением.
- **Консоль.** В консоли (cmd, PowerShell, Windows Terminal) исправляется только последнее набранное слово, выделение не используется. Так Ctrl+C не прерывает выполняемую команду.
- **Очень большой буфер.** Если в буфере очень большой объём данных (например, диапазон из Excel), ввод может ненадолго притормозить.

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
dotnet build TextExpander.sln
dotnet test TextExpander.sln
publish.cmd
```

`publish.cmd` собирает один файл `dist\TextExpander.exe`; для запуска нужен .NET 8 Desktop Runtime.

## Устройство

| Файл | Назначение |
|---|---|
| `src/TextExpander/TrayApp.cs` | Значок в трее, меню, связка всех частей, перезагрузка шаблонов |
| `src/TextExpander/InputMonitor.cs` | Глобальный перехват клавиатуры и мыши, горячие клавиши |
| `src/TextExpander/TriggerMatcher.cs` | Поиск кодового слова в конце набранного текста |
| `src/TextExpander/Paster.cs` | Работа с буфером обмена и вставка |
| `src/TextExpander/LayoutConverter.cs` | Перевод QWERTY ↔ ЙЦУКЕН |
| `src/TextExpander/WordTracker.cs` | Последнее набранное слово |
| `src/TextExpander/SnippetStore.cs` | Чтение и запись `snippets.json` |
| `src/TextExpander/SnippetsForm.cs` | Окно «Шаблоны» |
| `src/TextExpander/Autostart.cs` | Автозапуск через реестр (HKCU\…\Run) |
